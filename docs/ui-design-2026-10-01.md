# Stream Studio UI refresh

The interface now uses a quieter graphite palette with a mint accent, a consistent line icon set, and clearer alignment between the sidebar, page title, search, and content. Light mode uses the same hierarchy with emerald controls. The other six palettes continue to use their existing colors through shared resources.

## Changes

- Library and settings navigation use one vector icon system. Selected rows have a restrained accent indicator, readable labels, and compact counts.
- Live cards keep a 16:9 preview, separate the channel name from the full-width stream title, and use a clear live badge. Category artwork uses its original 3:4 proportions; two posters fit at a 360-pixel window width.
- Settings and downloads share icon headings, dividers, spacing, and filled toggle states. Hover and keyboard focus remain visible.
- Search and page titles share an alignment edge. The toolbar measures the navigation width when allocating room for playback actions, including after resizing while Settings is open.
- The app, detached player, setup window, maintenance helper, and installer icon source use Stream Studio's mark. `Assets/Studio.svg` is the source; `scripts/create-studio-icon.ps1` renders nine Windows icon sizes from 16 to 256 pixels.

## Verification

`scripts/dev.ps1 Check` passed the final full suite: 1,453 tests passed and 262 desktop-dependent tests skipped. It also passed locked restore, formatting verification, PowerShell syntax, tooling contracts, native dependency verification, and the Release build with warnings treated as errors. The logs are recorded in `.artifacts/premium-ui/check.log`.

`scripts/dev.ps1 Test -Interactive -Filter 'studio ' -NoRestore` passed all 22 selected tests with zero skips. This includes visible-window repainting across all palettes and physical arrow-key and Enter navigation in search. The Release build completed with zero warnings and errors. The log is `.artifacts/premium-ui/desktop-ui.log`.

The new layout checks render actual WPF controls in all eight palettes at 1320 × 820, 700 × 640, and 360 × 640. They check page alignment, category commands, poster proportions, two-column compact layout, final-row reachability, and navigation after resizing Settings. Library section labels must meet 4.5:1 contrast in every palette. The contrast check also requires at least 4.5:1 for primary, secondary, muted, placeholder, and dim text on the default dark and light surfaces, and for duration labels over bright thumbnails.

Existing tests also cover library selection, card geometry and scrolling, settings autosave, download actions and errors, search keyboard behavior, and color emoji titles. The rail test resolves the named indicator and samples its rendered center, so it continues to verify selection without depending on the previous decorative dimensions.

58 additional page renders are saved under `.artifacts/premium-ui/verified/`. Public Twitch preview and category images were downloaded for local visual review and supplied through `SVS_UI_IMAGE_FIXTURES`; these images are not bundled with the application. Without that optional variable, the tests use deterministic local bitmaps.

All nine native icon frames were decoded and their dimensions checked. Native window capture timed out during the initial computer-use review; the previews in this report come from the app's WPF rendering tests. A final launch through the native automation tool could not be completed: its JavaScript kernel failed to restart, including after the documented reset, with `windows sandbox failed: helper_unknown_error: setup refresh had errors`. The successful focused desktop UI tests used the repository's existing WPF test harness.

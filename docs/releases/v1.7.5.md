# Stream Studio 1.7.5

This release publishes the current Stream Studio app and fixes the packaged updater's installation detection and restart path.

**One-time manual upgrade required for 1.7.1 and earlier:** download and run **StreamlinkVlcStudio-Setup.exe**. Those builds confuse the .NET extraction cache with the installed application directory, so they cannot reliably install this fix through their own updater. After installing 1.7.5, managed installations support verified in-app updates.

- The updater and its helper now resolve their directory from the actual executable, including self-extracting releases.
- Quiet installation and related-bundle removal create a valid hidden installer window handle.
- Public package names, the signing key, and the managed install path stay compatible across the Stream Studio rename.
- Update completion records and verified downloads retain their existing location.
- Includes the current playback, replay pause/resume, Browse scrolling and refresh, chat, and channel-point improvements.
- Verified automatic downloads remain optional. Installing still requires **Restart and install**. ZIP/PowerShell installations receive notifications and are updated manually.

The managed app is installed at `C:\Program Files\Streamlink VLC Studio\StreamlinkVlcStudio.exe`, with a **Stream Studio** Start Menu entry. Setup embeds Streamlink and VLC.

`UPDATE-MANIFEST.json` and `UPDATE-MANIFEST.sig` use the existing RSA-PSS/SHA-256 trust key. `SHA256SUMS.txt` covers all public assets. The installer remains Authenticode-unsigned and may show an unknown-publisher prompt.

# Stream Studio 1.8.10

This release improves the LAN browser player, account connection flow, and playback reliability.

## Improvements and fixes

- **Browser player controls and layout.** Refined responsive layouts, navigation, sign-in, mobile playback controls, and the VOD library.
- **More reliable saved playback.** Completed browser videos keep their watched status after closing. Volume and bookmark saving handle failures more reliably, including when signing out or saving several players.
- **Playback and chat fixes.** A delayed replay lookup can no longer restart a stopped or closed stream. Replay timing, overlay cleanup, and Kick chat connection handling are more robust.
- **Account connection fixes.** Browser sign-in preserves encoded authorization URLs, and the setup wizard displays the exact callback URLs used by the app. Account setup documentation clarifies the required callback spelling.
- **Reliability and credential protection.** Improved bounded web-response reads, URL validation, log redaction, browser refresh handling, and VOD metadata persistence.

## Updating

Open **Settings > Advanced > Updates** to check for this release. Setup and owned ZIP installations can download a verified package and choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from this release.

If you are upgrading from 1.7.1 or earlier, run Setup manually once to enable the repaired in-app updater. ZIP installations of 1.8.6 or earlier also need one manual upgrade before they can use in-app ZIP updates. This release includes a signed update manifest and SHA-256 checksums.

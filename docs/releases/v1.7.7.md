# Stream Studio 1.7.7

This release improves live-stream recovery, VOD playback and watch history, and chat readability in smaller windows.

- Automatically reconnects live streams after playback ends unexpectedly or video output stalls, while preserving the tab, chat, quality, and audio settings.
- Speeds up VOD startup, saved-position resume, and seeking, including long Twitch archives and the first seek behind a live broadcast.
- Saves VOD progress, shows watched status, and marks completed archives as watched when playback reaches the end. Finished videos can restart from the beginning or seek backward.
- Fixes playback completion at muted Twitch VOD endings and keeps archive chat on its replay timeline through chat restarts and layout changes.
- Improves overlay text and emote clarity when video is scaled down, while preserving saved panel sizes and message layout during window resizing.
- Reuses existing stream tabs promptly, preserves manually paused playback, and prevents a delayed stream open from clearing a newer search.
- Improves native chat connection handling, fragmented Kick messages, and shutdown cleanup.
- Adds a simpler development command and makes release uploads resumable, with asset verification before publication.

Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation. Managed installations on 1.7.5 or 1.7.6 can receive this release through the verified in-app updater. ZIP/PowerShell installations receive update notifications and are updated manually.

**Upgrading from 1.7.1 or earlier:** download and run **StreamlinkVlcStudio-Setup.exe** once, because those versions cannot reliably install the updater fixes themselves.

The release includes a signed update manifest and `SHA256SUMS.txt` covering all public assets. The installer remains Authenticode-unsigned and may show an unknown-publisher prompt.

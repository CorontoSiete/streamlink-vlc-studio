# Stream Studio 1.7.1

This release publishes the current Stream Studio desktop app with playback, browsing, chat, and updater reliability improvements.

- More reliable replay pause/resume, video sizing, picture-in-picture, and window capture.
- Smoother Browse scrolling and refreshes, with lower repeated network and rendering work.
- Twitch channel-point bonus support, account-field masking, and chat recovery improvements.
- Optional automatic downloading of verified updates, independent manual update checks, retry/backoff, stalled-download recovery, and reuse of verified downloads after an interrupted installation.
- Installer retry and cancellation fixes, improved VLC detection, and preservation of settings during upgrades.

## Updating

Managed 1.7.0 installations can use **Check for updates**, **Download update**, then **Restart and install**. The app is displayed as Stream Studio; the public package names and managed installation path remain compatible with the updater already installed on users' computers.

Download **StreamlinkVlcStudio-Setup.exe** for a normal installation. It embeds the app, Streamlink, and VLC. The managed app remains at `C:\Program Files\Streamlink VLC Studio\StreamlinkVlcStudio.exe`; the Start Menu entry is **Stream Studio**.

Update completion records and verified downloads remain under `%LOCALAPPDATA%\StreamlinkVlcStudio\Updates` so an upgrade started by 1.7.0 can report its result and clean up its staged installer.

Versions 1.6.65 and earlier need to run Setup manually once. ZIP/PowerShell installations receive update notifications and must be updated manually.

The signed `UPDATE-MANIFEST.json` and `UPDATE-MANIFEST.sig` use the existing RSA-PSS/SHA-256 trust key. `SHA256SUMS.txt` covers the release assets. The installer is not Authenticode-signed and may show Windows' unknown-publisher prompt.

# Stream Studio 1.7.6

This release adds Kick follow import and improves replay chat, background refresh, and update cleanup.

- Import your followed Kick channels through **Settings > General > Followed channels > Detect Kick follows**. Sign in on Kick and select **Import follows**; both live and offline follows are saved alongside your manual entries.
- Twitch chat continues fetching new comments after seeking behind an ongoing broadcast. Replay transitions, growing archives, and unavailable chat recover more reliably.
- Improves replay seek previews and redirected Twitch playlists, including subscriber-only and muted VOD playback.
- Reduces duplicate followed-channel refreshes, batches application log updates, and improves badge and emote catalog lifetimes.
- Fixes account, chat-send, notification, and asynchronous shutdown edge cases.
- Improves removal of expired and superseded update downloads, retries locked leftovers, and keeps cache cleanup independent of online update checks.
- Preserves the ZIP uninstaller's keep-user-data option across its handoff and removes temporary helpers and empty managed folders while preserving unrelated files.

Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation. Managed installations on 1.7.5 can receive this release through the verified in-app updater. ZIP/PowerShell installations receive update notifications and are updated manually.

**Upgrading from 1.7.1 or earlier:** download and run **StreamlinkVlcStudio-Setup.exe** once, because those versions cannot reliably install the updater fixes themselves.

The release includes a signed update manifest and `SHA256SUMS.txt` covering all public assets. The installer remains Authenticode-unsigned and may show an unknown-publisher prompt.

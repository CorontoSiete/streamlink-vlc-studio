# Stream Studio 1.8.0

This release adds live stream previews and broader Twitch/Kick browsing, improves replay controls and startup behavior, and reduces resource use during multi-stream playback.

- Optionally preview live streams on hover in Followed, Browse, search results, and Recent. Previews are muted and stop when you move away, open a stream, hide the page, or turn the setting off.
- Search Twitch and Kick channels with keyboard navigation, restore scroll position per library page, and keep Discover's position when returning from a category.
- Resume Twitch and Kick VODs from the last confirmed position. Configure separate skip shortcuts and durations, and keep replay seeks paused until the requested frame is ready.
- Improve multistream behavior, including hidden-tab playback monitoring, stream cancellation during startup, and responsive window and picture-in-picture handling.
- Reduce native chat rendering CPU and allocations, release hidden chat rows, and reuse unchanged video layouts.
- Improve updater, installer, and uninstall recovery for expired downloads, locked files, restarts, and interrupted cleanup.

Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation. Managed installations can receive this release through the signed in-app updater. ZIP/PowerShell installations receive verified release notifications and are updated manually.

# Stream Studio 1.7.9

This release adds Kick clipping, fixes green replay video, and reduces playback and chat-overlay CPU usage.

- Creates a 30-second clip from the selected live Kick stream in the background, assigns an automatic title, and opens the confirmed clip in your browser. Sign in through **Detect Kick follows** in Settings first if needed.
- Fixes green frames after HLS replay seeks and decoder restarts with GDI video output by selecting DXVA2 hardware decoding.
- Keeps replay video black until the requested playback position is ready, including prepared live replays.
- Enables hardware decoding with the verified bundled chat compositor and reuses unchanged overlay images to reduce CPU work and pixel-buffer allocations.
- Replaces the Clip and Never mute toolbar text with compact icons while preserving tooltips and accessible names.

Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation. Managed installations on 1.7.8 can receive this release through the verified in-app updater. ZIP/PowerShell installations receive update notifications and are updated manually.

**Upgrading from 1.7.1 or earlier:** download and run **StreamlinkVlcStudio-Setup.exe** once, because those versions cannot reliably install the updater fixes themselves.

The release includes a signed update manifest and `SHA256SUMS.txt` covering all public assets. The installer remains Authenticode-unsigned and may show an unknown-publisher prompt.

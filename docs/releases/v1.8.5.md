# Stream Studio 1.8.5

More control over playback, smoother navigation, and more dependable setup.

## Playback & navigation

- **Choose what keeps playing.** Pause inactive VOD tabs independently of live streams in **Settings > Playback**.
- **Get back to watching.** Improved navigation from Settings and more reliable browser handling for followed channels.
- **Refreshed icons.** Updated app and installer icons give Stream Studio a more consistent look.

## Setup & reliability

- **One complete installer.** Setup includes reviewed offline installers for Streamlink, VLC, and WebView2, and checks that the app's playback and interface components can start.
- **Repair interrupted updates.** Run the same Setup version again to recover an incomplete installation, even if the app was replaced before another component failed.
- **Restore missing app files.** Running Setup again repairs missing application files, including when launched by an older updater.

## Updating

**Installed with Setup?** Open **Settings > Advanced > Updates**. Download the verified update, then select **Restart and install**. Update checks are on by default; automatic downloads are optional.

**Installing for the first time?** Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation.

**Using ZIP or PowerShell?** Release notifications are verified, and updates are installed manually.

**Upgrading from 1.7.1 or earlier?** Run the Setup installer manually once to enable the working in-app updater.

### Download verification

Updates use a signed `UPDATE-MANIFEST.json` with a detached RSA-PSS/SHA-256 signature. SHA-256 checksums cover all public release files. Before publication, release checks verify the packaged updater, a real managed upgrade, runtime startup, and repair.

# Stream Studio 1.8.5

- Include reviewed offline Streamlink, VLC, and WebView2 installers, and verify that the installed app can initialize its playback, browser, drawing, and text runtimes.
- Keep incomplete updates repairable at the same version, including when Setup replaced the app before a dependency failed.
- Repair missing application files when an existing Setup package runs again, including passive launches from older update helpers.
- Add a separate setting to pause inactive VOD tabs while retaining the existing live-stream setting.
- Improve stream navigation from Settings, followed-channel browser handling, and the app and installer icons.

Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation. Managed installations receive this release through the signed in-app updater. Automatic update checks are enabled by default; automatic downloads can be enabled under **Settings > Advanced > Updates**. Select **Restart and install** after the download is verified.

ZIP/PowerShell installations receive verified release notifications and are updated manually. **Upgrading from 1.7.1 or earlier:** run the Setup installer manually once to migrate to the working updater.

The release includes a detached RSA-PSS/SHA-256 signature for `UPDATE-MANIFEST.json` and SHA-256 checksums for all public release files. The release workflow verifies the packaged updater, a real managed upgrade, runtime initialization, and repair before publishing.

# Stream Studio 1.8.9

Watch on your local network, connect your accounts more easily, and update ZIP installations in the app.

## New features

- **LAN browser player.** Start the optional HTTPS server from the desktop app to watch Twitch and Kick streams on a compatible phone, computer, or TV on your private network. Web accounts have separate passwords and playback preferences. Browse streams, use chat and replay controls, manage follows, and access downloads from the browser.
- **Simpler account setup.** Connect Twitch and Kick from the first-run wizard or Settings using your browser. The Kick connection uses the publisher's token service, so a personal developer-app secret is no longer required. Existing personal registrations remain supported.
- **Follow channels.** Follow Twitch and Kick channels from the player, with confirmation from the platform before the button changes state.
- **More useful offline cards and discovery.** Offline followed channels show banners and last-live information when available. Loading and category artwork recover more reliably, and search and browser navigation are smoother.
- **VOD format choices.** Save or convert supported downloads to MP4 without re-encoding their audio and video, with cleanup and storage improvements.

## Playback, chat, and updates

- **Smoother playback speed changes.** Native VLC playback keeps video and audio moving through speed changes, including live replay.
- **More reliable chat.** Twitch badges and animated emotes render more consistently; Kick chat reconnects more reliably. The browser player adds chat layout and overlay controls.
- **In-app ZIP updates.** Owned ZIP and PowerShell installations can download the signed ZIP release, then install it in place with **Restart and install**. Automatic downloads remain optional; installation still needs your explicit restart action. Setup installations continue to use the signed Setup package.
- **Security and reliability fixes.** Tightened account callbacks, replay URL validation, file writes, and update package handling.

## Updating

Open **Settings > Advanced > Updates** to check for this release. Setup and owned ZIP installations can download a verified package and choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from this release.

If you are upgrading from 1.7.1 or earlier, run Setup manually once to enable the repaired in-app updater. ZIP installations of 1.8.6 or earlier also need one manual upgrade before they can use in-app ZIP updates. The release includes a signed update manifest and SHA-256 checksums for its public files.

# Stream Studio 1.8.11

This release adds discovery language filters and improves browser playback, search, chat, and application reliability.

## Improvements and fixes

- **Remember discovery languages.** Filter live streams by language in desktop Discover and the browser player. Each category remembers its choice separately for Twitch and Kick, and each browser account keeps its own preferences. Refresh and pagination preserve the selected language.
- **Restore Kick browser playback.** The browser media proxy now handles Kick's prefetch playlist hints so affected live broadcasts can play normally.
- **More reliable streamer search.** Search commands handle cancellation and errors safely, and search popups dismiss and reopen more reliably.
- **Protect browser chat drafts.** Sending a message preserves any new text entered while the request is pending. Repeated clicks share the pending send, and failed requests keep the draft for retry.
- **Browser controls and saved state.** Improved keyboard shortcut validation, pagination, playback state, saved language choices, and account workspace cleanup.
- **Playback and chat cleanup.** Improved cancellation, connection shutdown, overlay scheduling, and playback resource cleanup. Native Kick chat now preserves supported channel names without truncation.
- **Updated build and installation tools.** Updated the bundled .NET runtime to 10.0.14 and improved native installer reliability on systems with long search paths.

## Updating

Open **Settings > Advanced > Updates** to check for this release. Setup and owned ZIP installations can download a verified package and choose **Restart and install**. For a first installation, download `StreamlinkVlcStudio-Setup.exe` from this release.

If you are upgrading from 1.7.1 or earlier, run Setup manually once to enable the repaired in-app updater. ZIP installations of 1.8.6 or earlier also need one manual upgrade before they can use in-app ZIP updates. This release includes a signed update manifest and SHA-256 checksums.

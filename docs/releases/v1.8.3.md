# Stream Studio 1.8.3

- Fix replay playback speed changes, clock recovery, and seeking, including transitions between fast and slow playback.
- Add a configurable Space shortcut to pause or resume streams in the main, fullscreen, and detached players.
- Keep the volume indicator clear of replay seek controls, including in compact layouts and finished VODs.
- Load Twitch category viewer counts faster and improve profile avatar rendering.
- Improve followed-channel pinning and navigation back to recent streams.
- Preserve custom Streamlink network and authentication settings during direct VOD and live-preview resolution.
- Improve playback cleanup, chat link parsing, measurement tools, and shared development and CI checks.

Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation. Managed installations receive this release through the signed in-app updater. Automatic update checks are enabled by default; automatic downloads can be enabled under **Settings > Advanced > Updates**. Select **Restart and install** after the download is verified.

ZIP/PowerShell installations receive verified release notifications and are updated manually. **Upgrading from 1.7.1 or earlier:** run the Setup installer manually once to migrate to the working updater.

The release includes a detached RSA-PSS/SHA-256 signature for `UPDATE-MANIFEST.json` and SHA-256 checksums for all public release files. The release workflow verifies the packaged updater and a real managed installation upgrade before publishing.

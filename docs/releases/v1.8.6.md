# Stream Studio 1.8.6

Find videos more easily, see what changed after an update, and recover interrupted installations.

## Browsing & playback

- **Choose the right channel.** Twitch and Kick video searches show matching channels before loading their videos, with more reliable cancellation and pagination.
- **Clearer browsing.** Category artwork, channel thumbnails, and Home card layouts work more consistently.
- **Smoother playback.** Improved seeking, live recovery, replay cleanup, and Twitch playback authentication.
- **More dependable chat.** Improved overlay rendering, connection cleanup, and chat behavior when switching or closing streams.

## Updates & reliability

- **Read what changed.** The first launch after an update opens the installed version's changelog. Revisit it in Settings and browse earlier release notes, even offline.
- **Recover interrupted updates.** The updater saves repair information before starting Setup, so an interrupted installation can still be repaired after restarting the app.
- **Safer setup and removal.** Improved handling of competing installation processes, app shutdown, missing files, and quiet repair.
- **More reliable background work.** Improved settings saves, cancellation, browser cleanup, and timer handling.

## Updating

**Installed with Setup?** Open **Settings > Advanced > Updates**. Download the verified update, then select **Restart and install**. Update checks are on by default; automatic downloads are optional.

**Installing for the first time?** Use **StreamlinkVlcStudio-Setup.exe** for the normal Windows installation.

**Using ZIP or PowerShell?** Release notifications are verified, and updates are installed manually.

**Upgrading from 1.7.1 or earlier?** Run the Setup installer manually once to enable the working in-app updater.

### Download verification

Updates use a signed `UPDATE-MANIFEST.json` with a detached RSA-PSS/SHA-256 signature. SHA-256 checksums cover all public release files. Before publication, release checks verify the packaged updater, a real managed upgrade, runtime startup, and repair.

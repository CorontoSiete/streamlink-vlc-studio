# Twitch-style channel watch page

The LAN web player now opens a dedicated channel page with an edge-to-edge video surface, controls over the video, channel avatar and live badge, broadcast title, category, tags, viewer count, uptime, follow/share actions, and Twitch subscription links. The About card includes the broadcaster's public bio, follower count, partner badge, and social links. Original Twitch panel images, links, and Markdown descriptions appear below it in responsive 320-pixel columns, preserving each channel's panel order. Nothing is hardcoded to the reference streamer.

Channel profiles load independently of playback through the authenticated `channel/profile` command, scoped to an existing player. The desktop fetches public provider metadata, caches it for 45 seconds across devices, and bounds the cache to 256 channels. Active players refresh metadata once per minute. A profile failure leaves playback usable and offers retry. Missing Twitch social-link permissions fall back to social URLs published in the channel's own panels. Kick channels use their available public bio, avatar, social links, category and stream metadata.

When the short bio is empty but the channel supplies panels, the About card points to those panels with **View channel panels**. The button scrolls to and focuses that player's panel region. Only panels with displayable text or a safe image count. This avoids claiming the streamer has no biography when their introduction is in a panel. Panel order and content are preserved; sponsor descriptions are never guessed to be biographies. See [the ImperialHal diagnosis and verification](imperialhal-bio-2026-10-22.md).

Provider descriptions are rendered as text or a limited Markdown subset with DOM nodes. Raw HTML is never interpreted. Images require HTTPS, links permit HTTP/HTTPS without embedded credentials, and external links use `noopener noreferrer`. Provider account credentials are never involved in profile requests. The existing TLS, authentication and content-security boundaries are unchanged.

Subscribe, Gift a Sub and Bits open Twitch's own pages. Personalized promotions and Twitch extension widgets are not fabricated; channels with extensions offer a link to their interactive panels and leaderboards on Twitch. These public website APIs can change independently of the app.

Back to library and Escape return to browsing while preserving open streams. Selecting a stream tab returns to its watch page. Existing multi-stream, replay, quality/speed selection, saved volume, picture-in-picture, fullscreen and movable overlay chat remain available. Theater mode hides the channel rail. Fullscreen hides the bio and panels.

Verified on 2026-10-22: Release build succeeds with zero warnings/errors. All 23 LAN tests pass with zero skips, including actual HTTPS authentication, browser video decoding, safe profile/Markdown rendering, play/pause and volume controls, mobile channel layouts, transparent overlay chat, trusted pointer/touch movement, fullscreen and multi-stream. The 11 saved-volume and nine overlay-geometry JavaScript regressions also pass. A separate Chrome fixture checks all six library pages at nine widths and the watch page at seven widths from 320 to 1920 pixels, with no horizontal overflow or JavaScript errors. Real NICKMERCS public metadata and panel images were loaded and desktop/phone renders visually inspected. This does not establish live video delivery from Twitch or physical TV/phone/Linux compatibility. Logs and screenshots are under `.artifacts/twitch-watch/`.

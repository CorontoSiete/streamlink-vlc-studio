Stream Studio

Upgrading from 1.7.1 or earlier:

Those packaged clients cannot reliably install updates. Download and run
StreamlinkVlcStudio-Setup.exe manually once. Later managed releases can update
from inside the app.

Recommended latest install/update:

Download StreamlinkVlcStudio-Setup.exe from the latest GitHub release and run
it. Verify the download against SHA256SUMS.txt from the same release first.
The setup executable is a compressed, per-machine bundle containing the app
MSI and the reviewed, version-locked x64 Streamlink, VLC, and WebView2 installers. It
installs the app under C:\Program Files\Streamlink VLC Studio, installs missing
dependencies, creates the Start Menu shortcut, and offers to launch the app's
first-run setup wizard.
Setup verifies real runtime initialization before reporting success or enabling
Launch. The app includes its .NET, graphics, and text runtimes; no separate .NET
SDK, Python installation, or Visual C++ redistributable is required for the
reviewed payload. Streamlink's Windows installer includes its Python runtime.

The app checks for stable releases automatically. A managed Program Files
installation offers Download update, verifies it, and then offers the separate
Restart and install action. Release-zip installs are notification-only and open
the release page; they do not launch the per-machine updater.

Automatic checks continue while the app is open and retry network failures.
Download progress and Cancel download are available in the update banner and
Settings. Completed downloads are retained for up to seven days and reverified
after an app restart. Installation still starts with Restart and install.
The seven-day limit also applies while the app stays open. Expired packages
are cleaned up and must be downloaded again before installation.
An incomplete installation remains repairable even if the app's new version
was already copied. The updater retains a repair notice, verifies cached bytes
again, and can download a fresh signed installer after cache expiration. A
successful dependency health check clears that notice.

Running the same registered Setup version again repairs the app, including
passive updater launches. Repair can rerun its reviewed dependency installers
while retaining compatible newer runtimes. Verification includes Streamlink's
Twitch and Kick imports, VLC's playback and bundled app plugins, browser startup,
and the drawing and text runtimes.

Startup cleanup removes installers for versions already installed, partial
downloads older than 24 hours, and update logs older than 30 days. It also runs
offline or with automatic checks disabled. Once a replacement is verified,
superseded downloads are removed. Read-only cache files are removed, and locked
files do not prevent cleanup of other files. Locked leftovers are retried later.
Update results are still reported if temporary-file cleanup fails or a result
file is locked. If Windows must restart to finish an update, the app stays closed
until you restart Windows and launch it again.
The update helper retries temporary result-file locks. If saving its result
still fails, it reopens the app unless Windows needs to restart.

The normal setup is registered through WiX/Windows Installer, not the separate
per-user Uninstall.exe. Removing Stream Studio through Apps & features /
Control Panel removes the app and its shortcut but leaves the shared VLC,
Streamlink, and WebView2 installations. It also removes this Windows account's Streamlink VLC
Studio settings, logs, protected account secrets, replay caches, extracted
assets, update cache, and product-owned temporary files under
%APPDATA%\StreamStudio, %LOCALAPPDATA%\StreamStudio, and the
product temp folders. Clear the setup UI's data-removal checkbox, or run the
bundle with PurgeUserData=0, only when you intentionally want to keep that data.

Advanced PowerShell install is also available from the release zip:

Use 64-bit PowerShell. Dependency-only repair (-SkipApp) reads the installed
application's dependency requirements, including requirements from newer apps.

ZIP upgrades preserve user-created files and empty directories. The installer
waits for the app to close before copying those files, and aborts if the new
payload conflicts with them. Cleanup retries temporary locks, clears read-only
attributes, and continues removing unlocked files. If ZIP uninstall cannot
remove all managed application files, it preserves personal data and uninstall
registration for a retry. Use --preserve-user-data to keep personal data even
after successful removal.
Deletion locks on the app, uninstaller, or ownership records preserve the whole
set for retry. Once the app is copied, the PowerShell installer registers its
uninstaller before dependency setup, so a failed dependency remains removable.

1. Download StreamlinkVlcStudio-release.zip and SHA256SUMS.txt from the same
   release, verify the zip, and extract it to a normal folder.

2. Open PowerShell in the extracted folder and run:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -AppSource Local -Launch

In the default Auto mode, the script first downloads the latest final GitHub
release's UPDATE-MANIFEST.json and detached signature. It verifies RSA-PSS/
SHA-256 with the pinned 3072-bit release key before trusting any manifest field,
then verifies the ZIP's exact name, length, and SHA-256. SHA256SUMS.txt is checked
as an additional release-set check. If the release cannot be used, Auto falls
back only to a complete app payload beside install.ps1.
Normal install modes never fall back to an arbitrary GitHub Actions artifact;
artifact installation is an explicit developer-only mode that requires a trusted
40-character main-branch commit.

The script reads dependencies\windows-installers.json and installs the pinned
Streamlink and VLC builds and the supported WebView2 Runtime when no compatible
working x64 installation is present. WebView2 must meet the SDK-required minimum;
the current minimum is 152.0.4191.53. Newer shared runtimes are retained.
Downloads are checked by size and SHA-256 plus the recorded signature/product
metadata. By default, it installs the app under
%LOCALAPPDATA%\Programs\StreamStudio. It writes the detected paths to
%APPDATA%\StreamStudio\settings.json, creates a per-user Start Menu
shortcut, and registers the included Uninstall.exe for the current Windows user.

For a private repository, set GITHUB_TOKEN to a token with release-content read
access. Developer artifact mode additionally requires Actions read access.

Force GitHub app download:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -AppSource GitHub -Launch

Dependency-only setup from this extracted zip:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -SkipApp

Local app setup from this extracted zip:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -AppSource Local -Launch

Manual portable setup:

1. Extract the release zip to a normal folder, for example:
   C:\Users\you\Apps\StreamStudio

2. Install x64 Streamlink for Windows 8.5.0 or newer if a supported working
   installation is not already present.

3. Install VLC 64-bit 3.0.23 or newer if a supported working installation is
   not already present.

4. Install the x64 Microsoft Edge WebView2 Runtime 152.0.4191.53 or newer if
   a supported working installation is not already present. The full Setup
   executable and PowerShell installer handle all three dependencies for you.

5. Run StreamStudio.exe.

6. Open Settings and verify:
   - Streamlink executable points to streamlink.exe.
   - VLC directory points to the folder containing libvlc.dll.

The executable embeds the VLC chat overlay plugin and controller and extracts
them to local app data when needed. A local zip package can also include an
inspection/override copy under:
vlc-overlay\build

You do not need to set VLC overlay plugin directory for the included overlay.
Only set that field if you want to override the bundled overlay with a custom
vlc-overlay build.

Open streams from the app's home search bar, followed channels, Browse, or Recent.
The browser capture extension is no longer included. If you installed an older
copy in your browser, remove it from the browser's Extensions page.

Settings are saved under %APPDATA%\StreamStudio. Twitch OAuth, Kick
access/refresh tokens, and the Kick client secret are stored inside settings.json
in a Windows current-user DPAPI-protected ProtectedSecrets envelope. Other
settings remain readable JSON. The protected secrets cannot be moved to another
Windows user profile; treat settings.json and any recovery backups as
account-sensitive.

The PowerShell-path Uninstall.exe removes its registered shortcut, uninstall
entry, managed app payload (including modified managed files), current-user
product data, and product-owned temporary files. It removes its temporary
helper after exiting and preserves unrelated files added to the install
directory. VLC, Streamlink, and WebView2 remain installed. Run
Uninstall.exe --preserve-user-data only when you intentionally want to keep
%APPDATA%\StreamStudio and %LOCALAPPDATA%\StreamStudio.

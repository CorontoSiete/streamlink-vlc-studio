Streamlink VLC Studio

Recommended latest install/update:

Download StreamlinkVlcStudio-Setup.exe from the latest GitHub release and run
it. Verify the download against SHA256SUMS.txt from the same release first.
The setup executable is a compressed, per-machine bundle containing the app
MSI and the reviewed, version-locked x64 Streamlink and VLC installers. It
installs the app under C:\Program Files\Streamlink VLC Studio, installs missing
dependencies, creates the Start Menu shortcut, and offers to launch the app's
first-run setup wizard.

Inside the app, Settings > Advanced > Updates can start a latest-release update.
Release-zip installs use the bundled install.ps1; MSI/full-installer installs
download StreamlinkVlcStudio-Setup.msi and verify it against SHA256SUMS.txt
before launching Windows Installer.

The normal setup is registered through WiX/Windows Installer, not the separate
per-user Uninstall.exe. Removing Streamlink VLC Studio through Apps & features /
Control Panel removes the app and its shortcut but leaves the shared VLC and
Streamlink installations. It also leaves logs, settings, protected account
secrets, replay caches, and other user data under
%APPDATA%\StreamlinkVlcStudio and %LOCALAPPDATA%\StreamlinkVlcStudio.

Advanced PowerShell install is also available from the release zip:

1. Download StreamlinkVlcStudio-release.zip and SHA256SUMS.txt from the same
   release, verify the zip, and extract it to a normal folder.

2. Open PowerShell in the extracted folder and run:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -AppSource Local -Launch

In the default Auto mode, the script first downloads the latest final GitHub
release zip and verifies it against that release's SHA256SUMS.txt. If the release
cannot be used, Auto falls back only to a complete app payload beside install.ps1.
Normal install modes never fall back to an arbitrary GitHub Actions artifact;
artifact installation is an explicit developer-only mode that requires a trusted
40-character main-branch commit.

The script reads dependencies\windows-installers.json and installs the pinned
Streamlink and VLC builds when no same-or-newer detected version is present.
Downloads are checked by size and SHA-256 plus the recorded signature/product
metadata. By default, it installs the app under
%LOCALAPPDATA%\Programs\StreamlinkVlcStudio. It writes the detected paths to
%APPDATA%\StreamlinkVlcStudio\settings.json, creates a per-user Start Menu
shortcut, and registers the included Uninstall.exe for the current Windows user.

For a private repository, set GITHUB_TOKEN to a token with release-content read
access. Developer artifact mode additionally requires Actions read access.

Force GitHub app download:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -AppSource GitHub -Launch

Dependency-only setup from this extracted zip:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -SkipApp

Local app setup from this extracted zip:

   powershell.exe -ExecutionPolicy Bypass -File .\install.ps1 -AppSource Local -Launch

Manual portable setup:

1. Extract the release zip to a normal folder, for example:
   C:\Users\you\Apps\StreamlinkVlcStudio

2. Install Streamlink for Windows if it is not already installed.

3. Install VLC 64-bit if it is not already installed.

4. Run StreamlinkVlcStudio.exe.

5. Open Settings and verify:
   - Streamlink executable points to streamlink.exe.
   - VLC directory points to the folder containing libvlc.dll.

The executable embeds the VLC chat overlay plugin and controller and extracts
them to local app data when needed. A local zip package can also include an
inspection/override copy under:
vlc-overlay\build

You do not need to set VLC overlay plugin directory for the included overlay.
Only set that field if you want to override the bundled overlay with a custom
vlc-overlay build.

The release also includes the Brave/Chromium capture extension under:
browser-extension

To install it in Brave:
1. Open brave://extensions
2. Enable Developer mode.
3. Click Load unpacked.
4. Select the extracted browser-extension folder.

Keep StreamlinkVlcStudio.exe running before clicking a direct Twitch or Kick
channel link.

Only unmodified left-clicks on direct Twitch or Kick channel routes are captured.
VOD, clip, directory/category, settings, and other non-channel routes continue to
navigate in the browser.

Settings are saved under %APPDATA%\StreamlinkVlcStudio. Twitch OAuth, Kick
access/refresh tokens, and the Kick client secret are stored inside settings.json
in a Windows current-user DPAPI-protected ProtectedSecrets envelope. Other
settings remain readable JSON. The protected secrets cannot be moved to another
Windows user profile; treat settings.json and any recovery backups as
account-sensitive.

The PowerShell-path Uninstall.exe removes its registered shortcut, uninstall
entry, and unchanged managed app payload. It preserves user-modified or unmanaged
files and does not delete %APPDATA% or %LOCALAPPDATA% user data or uninstall VLC
or Streamlink.
